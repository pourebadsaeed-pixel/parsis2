# پارسیس ۲ - سیستم حسابداری PWA

سیستم جامع حسابداری تحت وب با قابلیت نصب روی موبایل و دسکتاپ.

## ✨ ویژگی‌ها
- مدیریت اشخاص (حقیقی/حقوقی)
- مدیریت کالا و خدمات
- کدینگ حساب‌های حسابداری
- ثبت اسناد حسابداری
- فاکتور فروش و خرید
- دریافت و پرداخت
- دفتر روزنامه، دفتر کل، تراز آزمایشی
- سود و زیان و ترازنامه
- پشتیبان‌گیری و بازیابی JSON
- کارکرد کامل آفلاین با IndexedDB
- نصب به‌عنوان PWA

## 🚀 اجرا
فقط فایل‌ها را روی یک سرور HTTPS (یا localhost) قرار دهید.

برای توسعه محلی:
```bash
npx serve
